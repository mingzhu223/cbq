# CBQ · 2D 随机室内清除 V1

**在线玩：** https://mingzhu223.github.io/cbq/

单文件网页小游戏。双击 `index.html` 就能玩，不装任何东西、不联网。

## 怎么玩

| 按键 | 作用 |
| --- | --- |
| **W A S D** | 移动（贴墙自动侧滑） |
| **鼠标** | 瞄准 |
| **鼠标左键** | 射击（可按住连发） |
| **R** | 换弹（弹匣打空会自动换） |
| **ESC / P** | 暂停 |
| **Q** | 退出到标题 |

目标：逐间清空房间，找到并打掉 BOSS。

## 层数循环

- 打倒 1 个 BOSS = 通过 1 层。
- 通关后弹出层结算，可以选「进入下一层」或「结束本局并记录」。
- 每下一层会换一张新地图，恢复 35 点生命和部分弹药，敌人血量和伤害逐层上升。
- 生命归零时本局结束，层数写入排行榜。

## 排行榜（本机）

- 只存在你这台机器的 localStorage 里，不联网、不同步。
- 榜上只有两列：**代号 + 通关层数**，上限 **9999999 层**（超出按 9999999 显示）。
- 同一代号只保留最好成绩，按层数从高到低排序，最多保留 30 条。
- 首次可以在标题页起一个代号；之后还能**改名一次**，改完锁定。
- 存档键是 `cbq_save_v2`，清掉它就能重置代号和排行榜。

## 每局都不一样

每次开始都会重新生成一层楼：

- **12~14 个房间**，由随机游走算法拼合，可能带环路
- **房间尺寸随机**（内部 9×9 ~ 15×15），不只是复制粘贴的方块
- **房间主题随机**：办公区 / 库房 / 机房 / 档案室 / 医务室 / 食堂 / 值班室，主题决定地板墙面配色和掩体摆法
- **掩体随机**：办公桌、货架、机柜、病床、餐桌……
- **BOSS 房**固定在离入口最远的位置，小地图上用 ★ 标出
- 敌人数、兵种（普通 / 重甲 / BOSS）按房间距离递增
- 每局种子会显示在开局提示里，便于复现

## 视野（重要）

你只有 **120° 锥形视野**：

- 锥形内按真实光线判定，墙、掩体、关着的门都会切断视野（射线扫出来的多边形）
- **锥形外基本全黑**，只有脚边一小圈（约 46px）还能看见地面
- **不在视野里的敌人完全不显示**，直接溶进黑暗；转到他们的方向才会出现
- **黑暗里的敌人不会乱动**：没察觉你的敌人原地静止，不踱步、不转枪口
- **看不见你的敌人不开枪**：已经在追你的敌人会继续移动，但只有你能看见他、且有视线时他才会开火
- 敌人开枪时，如果你看不见他，也看不到弹道和枪口火光——声音和命中会提醒你，但不会白送位置
- 小地图始终可见，用来判断房间位置、门的位置和已清理状态

## 门

- 每扇门都有**黄黑危险条纹门框**、四角高亮角标和**状态灯**（关门红 / 开门绿，缓慢闪烁），门口还有一圈暖光，远处就能认出来。
- 走近自动开；开枪也会打开附近的门；敌人开门有半秒前摇。
- 小地图上每个门口都有一个小琥珀点。

## 出生点

每次出生在入口房里**离门最远的一侧**（并尽量离墙留 2 格余量），不会一睁眼就站在门口。

## 对手规则

- **对手视野**：墙、掩体、关着的门都会挡他们的视线，只有真看见你才会开火
- **听觉**：枪声会把附近敌人引过来，但他们只会「怀疑」并去查看，不会直接全知
- **门**：走近自动开；开枪也会把附近的门打开；敌人开门有半秒前摇
- **补给**：医疗包 +30 血、弹药箱 +15 发，敌人也会掉

## 想改点什么

游戏逻辑都在 `index.html` 末尾的 `<script>` 里，几个好改的地方：

| 改什么 | 找哪里 |
| --- | --- |
| 玩家速度 / 血量 / 弹匣 | `P_SPEED`、`makePlayer`、`MAG_SIZE` |
| 敌人属性 | `ENEMY_TYPES` |
| 房间数量 | `genLevel` 里的 `TARGET` |
| 房间大小范围 | `genLevel` 里 `w = 9 + Math.floor(...)` 那两行 |
| 主题配色 / 掩体样式 | `THEMES`、`buildProps` |
| 敌人智商（视野、反应） | `updateEnemy` |

浏览器控制台里还留了调试接口 `window.__CBQ`（`validate()` 可检查所有房间连通性，`teleport(tx,ty)` 可传送）。

## 兼容性

Chrome / Edge / Firefox 新版均可。用键盘鼠标玩，不支持触屏。
