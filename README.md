# CBQ · 2D 随机室内清除 V2.5

**在线玩：** https://mingzhu223.github.io/cbq/

单文件网页小游戏。双击 `index.html` 就能玩，不装任何东西、不联网。

## 怎么玩

| 按键 | 作用 |
| --- | --- |
| **W A S D** | 移动（贴墙自动侧滑） |
| **鼠标** | 瞄准 |
| **鼠标左键** | 射击（可按住连发） |
| **E** | 翻滚闪避（向前 4 格，有无敌帧，冷却 0.9s） |
| **鼠标滚轮** | 放大 / 缩小视野 |
| **R** | 换弹（弹匣打空会自动换） |
| **H** | 脱离卡死（卡进墙里也会自动脱出） |
| **ESC / P** | 暂停（也可以点右下角「暂停」按钮；退出在暂停菜单里） |

目标：逐间清空房间，找到并打掉 BOSS。

## V2.5 修复

- **探索区不再“刷”敌人**：已经看过/照亮区域里的敌人保持可见（半透明记忆显示），不会在探索过的地方突然出现。
- **ESC 兼容**：同时识别 `Escape` / `Esc` / `keyCode 27`；右下角新增「暂停」按钮，ESC 失效时可以直接点。
- **步枪备弹 360**（之前误设为 180）。
- **墙角弹道**：步枪/轻机枪子弹不能穿墙；只有两格方块成对角、另一个对角是空的，且子弹贴着那个角时，才能从角缝穿过。
- **擦身索敌**：子弹从敌人周围 1 格内擦过时，该敌人自动索敌（不必命中）。
- **翻滚改键**：从 Q 改为 **E**（Q 不再有功能）。

## V2.3 改动

- **BOSS 房只有 BOSS**：不再带重甲护卫。
- **掉落**：除 BOSS 外每个敌人**必定掉落弹药**；BOSS 什么也不掉。
- **视野收窄到 90°**：比 V2.2 的 120° 更紧，转身和搜拐角更重要。
- **说明页**：标题页的「简报」改名为「说明」，并加一条提示：**拐角记得点射压制**。
- **代号前缀**：所有代号显示时统一加 **「整活·」**（输入框前固定显示，排行榜也带前缀）。

## V2.2 修复

- **清空后门一定开**：房间清空的瞬间，它的所有门会自动打开并**保持敞开**，不会再被自动关上；另外每帧都有兜底检查，已清空房间的门如果处于关闭状态会被强制打开。
- **已清空且连通的房间不再相互封闭**：清空房间之间的门会一直开着，撤退和回头搜刮不用再重新开门。
- BOSS 门规则不变：所有其他房间清空后才解锁。

## V2.1 修复

- **脱离卡死**：卡进实心格 0.3 秒后自动挪到最近的安全点；按 **H** 或暂停菜单的「脱离卡死」可手动脱出。门也不会再夹着玩家关上。
- **BOSS 门规则**：BOSS 房在**其他所有房间清空之前锁死**，清空后自动解锁；生成器保证 BOSS 房是死胡同，不会把别的房间锁在它后面。
- **走廊点亮**：清空一个房间后，它门口附近的走廊（约 5 格）也会一起照亮，方便撤退和回头搜刮。

## V2 改动

- **开局选武器**：步枪（45 发、单发 35、精准）或轻机枪（150 发弹匣、单发 13、散布大、换弹 3 秒）。
- **薄墙小隔间**：房间里的柱子/掩体全部移除，改成薄墙隔出的 4 个半封闭小隔间，**敌人只在小隔间里生成**。
- **清空才开门**：你所在房间没清空时，这个房间的所有门锁死（红色挂锁 + 红灯）；清空后自动解锁。
- **已清房间全亮**：清空的房间整间照亮，不再受 90° 视野限制，方便回头搜刮和撤退。
- **全图小地图**：右上角小地图始终显示所有房间轮廓和门；未探索只画轮廓，已探索填充，已清空变绿，当前房间高亮，BOSS 房红星。
- **增援小队**：从第 2 层开始，随机房间有概率藏一支三人小队（队长 + 两名队员）。**生成时没有任何提示**；他们会保持三角队形推进，在黑暗中会慢慢走回默认站位。

## 层数循环

- 打倒 1 个 BOSS = 通过 1 层。
- 通关后弹出层结算，可以选「进入下一层」或「结束本局并记录」。
- 每下一层会换一张新地图，恢复 35 点生命和部分弹药，敌人血量和伤害逐层上升。
- 生命归零时本局结束，层数写入排行榜。

## 排行榜（本机）

- 只存在你这台机器的 localStorage 里，不联网、不同步。
- 榜上只有两列：**代号 + 通关层数**，上限 **9999999 层**（超出按 9999999 显示）。
- 同一代号只保留最好成绩，按层数从高到低排序，最多保留 30 条。
- 首次可以在标题页起一个代号；之后还能**改名一次**，改完锁定。
- 存档键是 `cbq_save_v2`，清掉它就能重置代号和排行榜。

## 每局都不一样

每次开始都会重新生成一层楼：

- **12~14 个房间**，由随机游走算法拼合，可能带环路
- **房间尺寸随机**（内部 13×10 ~ 21×23），单边 17 格及以上的概率为 55%
- **房间主题随机**：办公区 / 库房 / 机房 / 档案室 / 医务室 / 食堂 / 值班室
- **隔间布局随机**：薄墙的切分位置和门洞方向每局都不同
- **BOSS 房**固定在离入口最远的位置，小地图上用 ★ 标出
- 敌人数、兵种（普通 / 重甲 / BOSS）按房间距离递增
- 每局种子会显示在开局提示里，便于复现

## 视野（重要）

你只有 **90° 锥形视野**：

- 锥形内按真实光线判定，墙、薄墙、关着的门都会切断视野
- **锥形外基本全黑**，只有脚边一小圈（约 46px）还能看见地面
- **不在视野里的敌人完全不显示**，直接溶进黑暗；转到他们的方向才会出现
- **黑暗里的敌人不会乱动**：没察觉你的敌人原地静止；增援小队是例外，他们会在黑暗中慢慢归位
- **看不见你的敌人不开枪**：已经在追你的敌人会继续移动，但只有你能看见他、且有视线时他才会开火
- **已清空的房间和门口附近走廊彻底照亮**，不再受锥形限制
- 小地图始终可见，显示全图房间轮廓、门和探索进度

## 门

- 每扇门都有**黄黑危险条纹门框**、四角高亮角标和**状态灯**（关门红 / 开门绿，缓慢闪烁）。
- **房间没清空时门锁死**：门中央有红色挂锁，靠近也打不开；清空后自动解锁并**保持敞开**。
- 已清空房间之间的门会一直开着，不会相互封闭。
- **BOSS 门**要等其他所有房间都清空才会解锁（右上角会显示还剩几间）。
- 清空后走近自动开；开枪也会打开附近的门；敌人开门有半秒前摇。
- 小地图上每个门口都有一个小琥珀点。

## 卡死救援

- 卡进墙/门里超过 0.3 秒会自动找最近的安全点脱出。
- 按 **H**（或暂停菜单里的「脱离卡死」）可随时手动脱出。
- 门快关上时会检测玩家位置，不会夹着人关。

## 出生点

每次出生在入口房里**离门最远的一侧**（并尽量离墙留 2 格余量）。初始房间不刷敌人，出生即算已清空，周边走廊会点亮。

## 对手规则

- **对手视野**：墙、薄墙、关着的门都会挡他们的视线，只有真看见你才会开火
- **听觉/接近**：枪声会把附近敌人引过来；你进入敌人 **5 格**内（有视线）也会被发现
- **首次攻击**：敌人第一次发现你后，要 1.5 秒才会开第一枪；受伤后立刻索敌
- **增援小队**：三人一组，队长在前、两名队员在后方左右；接敌时保持队形，失去目标后会慢慢回到默认站位
- **补给**：医疗包 +30 血；弹药箱按武器补（步枪 +20 / 轻机枪 +40）；**除 BOSS 外每个敌人必定掉弹药**，另有 5% 概率掉血包；BOSS 不掉落

## 想改点什么

游戏逻辑都在 `index.html` 末尾的 `<script>` 里，几个好改的地方：

| 改什么 | 找哪里 |
| --- | --- |
| 玩家速度 / 血量 | `P_SPEED`、`makePlayer`、`ROLL_TIME` / `ROLL_DIST` |
| 武器数值 | `WEAPONS`（步枪 / 轻机枪） |
| 敌人属性 | `ENEMY_TYPES` |
| 房间数量 | `genLevel` 里的 `TARGET` |
| 房间大小范围 / 概率 | `genLevel` 里 `w = rng() < 0.55 ? ...` 那几行、`CELL` |
| 缩放范围 | `cv.addEventListener('wheel'...)` 里的 `0.7` / `1.8` |
| 隔间切分 | `buildPartitions`、`ensurePartitionConnectivity` |
| 增援概率 / 队形 | `spawnLevel` 里的增援判定、`SQUAD_SLOTS` |
| 敌人智商（视野、反应） | `updateEnemy` |

浏览器控制台里还留了调试接口 `window.__CBQ`（`validate()` 可检查所有房间连通性，`teleport(tx,ty)` 可传送，`killRoom(idx)` 可秒清房间）。
